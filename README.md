## Что это?
**Mayas** — Android-мессенджер на **Kotlin + Jetpack Compose**, который постепенно превратился из небольшого эксперимента в полноценный проект с чатами, группами, каналами, звонками, медиа и кучей настроек.

Главная идея простая: **открыл приложение → нашёл человека → написал.**

Без необходимости разбираться в десяти меню перед отправкой первого сообщения.

Mayas пока не претендует на звание идеального мессенджера. Он просто развивается, получает новые функции и иногда удивляет даже своего разработчика.

## Возможности

### Личные чаты

* Чаты в реальном времени
* Поиск пользователей по **username** \ номеру телефона
* Реакции
* Закрепление сообщений
* Несколько закреплённых сообщений
* Индикатор набора текста
* Статусы прочтения и просмотра
* Черновики сообщений
* Отложенная отправка
* Исчезающие сообщения
* Настройка темы конкретного чата
* Сохранённые сообщения

---

### Медиа

Mayas умеет работать не только с текстом:

* Изображения
* Голосовые сообщения
* Круглые видео («кружки»)

и всё ЛОЛ

---

###  Сообщения

Для сообщений есть дополнительные возможности:

* Стили сообщений
* Эффекты сообщений
* Реакции
* Отложенная отправка
* Исчезающие сообщения
* Системные сообщения для событий в группах и каналах ( не видел )

То есть обычное `привет` можно постепенно превратить во что-то гораздо менее обычное.

---

### Каналы

В Mayas есть каналы(удивительно):

* Создание каналов
* Публичные username каналов
* Подписка на каналы
* Управление публикациями
* Администраторы
* Права на публикацию
* Поиск публичных каналов
* Счётчик подписчиков
* Профиль канала

Канал можно найти через поиск по username и подписаться прямо из приложения.

---

### Звонки

В приложении есть поддержка звонков(удивительно):

* Голосовые звонки
* Пропущенные вызовы
* Отклонённые вызовы

Звонки используют WebRTC.

## Профили

Профиль пользователя — это не просто аватар и имя.

Поддерживаются:

* Username
* Имя
* Описание
* Аватар
* Свечение профиля
* Рамки аватара
* Статус-эмодзи
* Кастомизация имени
* Верификация
* Ранги
* Информация о последней активности
* Медиа профиля
* Ссылки
* Закреплённые сообщения

Для групп и каналов используются отдельные варианты профилей с информацией об участниках и подписчиках.

## Приватность и безопасность

В приложении есть настройки приватности, включая:

* Кто может видеть последнюю активность
* Настройки профиля
* Управление активными сессиями
* Блокировку пользователей
* Жалобы на пользователей
* Очистку чата
* Управление локальными данными и кэшем

**Важно:** Маяс не заявляет о сквозном шифровании чатов(пока что), если оно отдельно не реализовано. Не отправляйте через тестовую версию приложения данные, которые вы не готовы доверить серверной инфраструктуре проекта.

## Без VPN

Самое вкусное ! Оно работает так что ты просто :

Открыл → вошёл → написал.

При этом доступность самого приложения, Firebase, хостинга и других используемых сервисов может зависеть от сети и региона. ( Старался чтоб были доступны всгда )

## Требования

**Android 7.0+**

Некоторые функции требуют дополнительных разрешений, например:

* Камера
* Микрофон
* Уведомления
* Интернет ( а как без него ) 
* Чтение контактов 
* И т.д все разрешения можно прочесть в `app/src/main/AndroidManifest.xml`

Или прямой ссылкой https://github.com/dan1eIDT/Mayas/blob/master/app/src/main/AndroidManifest.xml
