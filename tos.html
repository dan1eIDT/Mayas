Добро пожаловать в Mayas. Используя приложение Mayas, вы соглашаетесь с настоящими условиями использования. Если вы не согласны с любым из положений данного документа, пожалуйста, прекратите использование приложения.

01О сервисе

Mayas — это приложение для обмена сообщениями, создания групп, общения, обмена файлами, персонализации профиля и использования цифровых функций, включая подписку Premium и виртуальную валюту.

02Возрастные ограничения

Используя Mayas, вы подтверждаете, что достигли возраста, разрешенного законодательством вашей страны для использования подобных сервисов.

Если вы не достигли необходимого возраста, использование приложения допускается только с согласия законного представителя.

03Создание аккаунта

Для использования большинства функций необходимо создать аккаунт.

Пользователь несет ответственность за сохранность своего аккаунта и безопасность устройства.

04Собираемые данные

Для работы приложения могут собираться:

  • UID пользователя
  • Имя пользователя
  • Отображаемое имя
  • Фотография профиля
  • Описание профиля
  • Список контактов внутри приложения
  • Сообщения
  • Группы
  • Файлы, отправленные пользователем
  • Изображения
  • Голосовые сообщения
  • Настройки приложения
  • Настройки профиля
  • Информация о подписке
  • Виртуальная валюта
  • Технические журналы ошибок
  • Идентификаторы устройства
  • Рекламный идентификатор (Advertising ID), если используется реклама

05Хранение данных

Данные могут храниться с использованием следующих сервисов:

  • Firebase Authentication
  • Cloud Firestore
  • Firebase Storage
  • Firebase Cloud Messaging
  • Firebase Crashlytics (при использовании)
  • Firebase Analytics (при использовании)

Также могут использоваться сторонние рекламные сервисы.

06Использование рекламы

В приложении может отображаться реклама.

Могут использоваться:

  • Yandex Mobile Ads
  • Google AdMob
  • Другие рекламные платформы

Некоторые объявления могут быть персонализированы в соответствии с настройками рекламной платформы.

Просмотр рекламы с вознаграждением осуществляется исключительно по инициативе пользователя.

07Premium

Mayas Premium предоставляет дополнительные функции.

Подписка может включать:

  • Отключение части рекламы
  • Эксклюзивные темы
  • Эксклюзивные стили сообщений
  • Дополнительные возможности персонализации
  • Увеличенные лимиты
  • Другие Premium-функции

Подписка автоматически продлевается, если пользователь не отменил ее средствами магазина приложений.

08Виртуальная валюта

В приложении используются виртуальные монеты.

Монеты:

  • Не являются денежными средствами
  • Не подлежат обмену на реальные деньги
  • Не могут быть выведены
  • Могут использоваться только внутри приложения
  • Могут начисляться за просмотр рекламы, участие в акциях или покупки

09Пользовательский контент

Пользователь сохраняет права на размещаемый им контент.

Размещая материалы в Mayas, пользователь предоставляет приложению право хранить, передавать и отображать данный контент исключительно для обеспечения работы сервиса.

10Запрещается

  • Нарушать законодательство
  • Распространять вредоносное ПО
  • Публиковать материалы, нарушающие авторские права
  • Использовать спам
  • Заниматься мошенничеством
  • Выдавать себя за других лиц
  • Использовать автоматизированные средства для накрутки
  • Распространять запрещенные материалы
  • Нарушать работу приложения

11Блокировка аккаунта

Администрация имеет право ограничить или прекратить доступ к сервису в случае нарушения настоящих условий.

12Удаление аккаунта

Пользователь может удалить аккаунт.

После удаления часть информации может быть удалена без возможности восстановления.

Некоторые данные могут храниться ограниченное время, если это требуется законодательством или необходимо для обеспечения безопасности сервиса.

13Авторские права

Приложение предоставляется «как есть».

Разработчик не гарантирует отсутствие ошибок, бесперебойную работу сервиса или полную сохранность пользовательских данных.

В максимально допустимой законом степени разработчик не несет ответственности за любые косвенные или прямые убытки, связанные с использованием приложения.

15Изменение условий

Настоящие условия могут быть изменены в любое время.

Продолжение использования приложения после публикации новой редакции означает согласие пользователя с обновленными условиями.
